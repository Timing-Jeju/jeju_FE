# UI 복원과 후속 작업 기준

사용자 요청에 따라 PR #6에서 제거하거나 바꾼 화면 요소를 PR #5 반영 상태(`2c38a89`) 기준으로 복원한다.

- 장소 검색: 가볼 만한 장소 제목, 정렬 버튼·선택 시트, 필터 칩을 복원한다. 아직 연결되지 않은 추천 정렬·필터는 실행 시 준비 중임을 안내한다.
- 장소 상세: 사진 표시 점, 복사 표시, 전화하기·지도보기·홈페이지 액션 행, 기존 이용 안내 행, 찜 버튼 문구를 복원한다. 미제공 정보는 실제 데이터로 만들지 않는다.
- 지도: 주변 장소 카드의 이미지·캡션·거리 행 배치를 복원하고 미지원 상태를 표시한다. 하트는 상세 화면으로 이동하지 않고 canonical ID로 즉시 찜·해제한다.
- 세 화면의 `StyleSheet` 정의는 기준 커밋과 동일하다. 실제 API·canonical ID·오류 처리·추가 페이지 조회는 유지한다.

임시 장소, 허위 거리, 영업 중·무료 기본값과 임시 일정 계산은 복원하지 않는다. 인증 및 생성 기능의 준비 상태 차단을 해제하는 작업도 아니다. 찜의 서버 동기화는 여전히 후속 작업이며 앱 상태에만 보관된다.

타입 검사, 린트, 기존 55개 테스트와 OpenAPI 생성 일치 검사를 수행했다. 상세 화면 기존 테스트에는 복원한 액션·정보 행 확인도 포함한다. 실제 iOS/Android 기기 화면 비교는 미실행이므로 완전한 시각적 동일성을 검증했다고 표현하지 않는다.

후속 API 연결은 기존 UI/UX를 유지한다. 화면 구조·스타일·동선을 변경해야 하는 경우 먼저 사용자에게 변경안을 설명하고 명시적인 동의를 받는다.
